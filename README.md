
#  Land Price Prediction

## 📌 Project Overview

This project focuses on predicting land prices using Machine Learning techniques with Python.

The project demonstrates how data analysis and machine learning can be used to explore factors that influence land prices and build a predictive model.

## 🎯 Objectives

- Understand and analyze land price data.
- Explore the relationship between input features and land prices.
- Apply machine learning techniques for price prediction.
- Evaluate the model's prediction performance.

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 📂 Project File

- `03_land_price_prediction.ipynb` – Jupyter Notebook containing the project implementation.

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/salmiyaka/land_price_prediction.git
   ```

2. Open the project folder.

3. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn jupyter
   ```

4. Open Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open `03_land_price_prediction.ipynb` and run the cells.
